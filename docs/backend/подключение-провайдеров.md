# Подключение LLM-помощника и распознавания речи

Ключи провайдеров хранятся только в корневом `.env`. Файл игнорируется Git и не должен
попадать в коммиты, скриншоты или клиентский JavaScript. Перед отправкой документов во внешний
LLM-провайдер убедитесь, что в них нет персональных и конфиденциальных данных.

1. Скопируйте `.env.example` в `.env` в корне репозитория.
2. Укажите `LLM_PROVIDER=deepseek` и новый `DEEPSEEK_API_KEY`.
   По умолчанию backend ждёт ответ модели до 120 секунд и отключает thinking для коротких
   структурированных задач. Эти параметры можно менять через `DEEPSEEK_TIMEOUT_SEC` и
   `DEEPSEEK_THINKING_ENABLED`; включение thinking может улучшить рассуждение, но увеличить время.
   Временные сбои (HTTP 408/429/5xx, таймаут, обрыв сети) повторяются до `DEEPSEEK_MAX_RETRIES`
   раз с экспоненциальной паузой от `DEEPSEEK_RETRY_BASE_SEC` до `DEEPSEEK_RETRY_MAX_SEC` и
   джиттером; заголовок `Retry-After` учитывается (не больше 30 секунд и не дольше срока
   прогона). Таймаут чтения запрос уже отправлен и оплачен, поэтому повторяется не более одного
   раза; отказы до отправки (обрыв соединения, 429, 5xx) повторяются до лимита. Весь прогон ограничен `RUN_DEADLINE_SEC`, а
   объём текста источников за прогон — `LLM_CONTEXT_BUDGET_CHARS` (лишнее обрезается, это видно
   в `warnings` прогона). Токены каждого вызова пишутся в `llm_calls`.
3. Перезапустите локальный backend (`make up` для Compose либо перезапуск dev-сервера).
4. Откройте серверный проект, задайте вопрос помощнику и проверьте ответ.

Для голосовой расшифровки отдельно укажите `STT_PROVIDER=deepgram` и новый `DEEPGRAM_API_KEY`.
Ключи можно добавить только локально в `.env`; не вставляйте их в исходники, GitLab или чат.

Для серверного проекта endpoint принимает его id, вопрос, последние сообщения диалога и актуальный
BPMN XML. Backend сам загружает название, описание, активные источники и открытые вопросы проекта.
Для локального черновика браузер отправляет его заголовок, исходное описание и текущую схему только
в момент вопроса; backend не сохраняет этот черновик. Контекст ограничен по объёму. Модель
консультирует и предлагает изменения, но не редактирует схему.
