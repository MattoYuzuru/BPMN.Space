# Примеры: вход → выход

Каждый пример — исходные материалы аналитика (`input/`) и записанный учебный граф BPMN 2.0
(`output/`). Схемы собраны кодом из описаний/IR, проходят официальные XSD OMG и
`bpmnlint:recommended`, открываются в bpmn.io. Они проверяют обработку графа и mock-сценарии;
качество живой модели оценивается отдельным прогоном тех же регламентов.
Пять текущих тем доступны в приложении: `GET /api/v1/examples`, «Создать из примера».

| Пример | Вход | Выход |
|---|---|---|
| `tp861/` — технологическое присоединение (ПП РФ № 861) | `regulation.md` — выжимка регламента; `meeting-note.txt` — расшифровка голосовой заметки, частично противоречит регламенту; `project-finances.docx` (и `.md`) — документ о расчётах | `diagram-v1.bpmn` — первая версия с допущениями; `diagram-v2.bpmn` — после заметки и ответов; `diagram-v3.bpmn` — после документа о финансах (дорожка «Финансовый отдел») |
| `work-permit/` — работы по наряду-допуску | `regulation.md` | `diagram.bpmn` |
| `energy-incident/` — восстановление энергоснабжения | `regulation.md`: роли, действия, безопасность, резерв, испытания | `diagram.bpmn`: 45 узлов, 51 поток, пять дорожек |
| `logistics-order/` — исполнение складского заказа | `regulation.md`: реквизиты, запас, оплата, транспорт, контроль и расхождения | `diagram.bpmn`: 49 узлов, 56 потоков, пять дорожек |
| `service-release/` — выпуск цифрового сервиса | `regulation.md`: проверка кандидата, миграция, реальный трафик и откат | `diagram.bpmn`: 44 узла, 50 потоков, пять дорожек |

`repair-outage/` сохраняется как архивная фикстура прежнего каталога. Учебный материал
вывода в ремонт по-прежнему доступен в разделе добавления источников.

В схемах: пул с дорожками по участникам, исключающие шлюзы с подписанными ветками «Да»/«Нет»,
параллельные шлюзы, циклы доработки через шлюз-слияние. Единственное предупреждение bpmnlint —
`fake-join` в `tp861/output/diagram-v1.bpmn`: так выглядит ранняя версия, v2 его исправляет.

Пересборка — `uv run --directory backend python scripts/build_fixtures.py` (см. `docs/backend/mock.md`).
